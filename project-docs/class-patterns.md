## Example Class Patterns

What's interesting is that Forever isn't trying to make every class equally good at every situation. It appears to be deliberately creating a matrix something like:

| If you specifically want... | Blizzard wants you thinking... |
|---|---|
| Highest sustained single-target melee DPS | **Rogue** |
| Sustained multi-target melee damage | **Warrior** |
| Longest-range physical damage | **Hunter** |
| Strongest ranged AoE | **Mage** |
| Strongest battlefield control | **Mage** |
| Best single-target healing | **Paladin** |
| Broadest healing toolkit | **Priest** |
| HoT-oriented healing | **Druid** |
| Group enhancement/buffs | **Shaman / Paladin** |
| DoTs, drains and attrition | **Warlock** |
| Permanent combat pet | **Hunter / Warlock** |
| Stealth and surgical control | **Rogue** |
| Tank/DPS/healer flexibility | **Druid** |
| Physical tanking/melee toolkit | **Warrior** |
| Totems | **Shaman** |

A perfectly balanced Forever raid therefore *shouldn't* consist of 40 characters who contribute approximately the same damage, CC, buffs and survivability under different visual effects. The intended design seems closer to:

> **Every class should have situations where the raid says, "I really wish we had one of those."**

And, equally importantly, every class is supposed to retain situations where another class is clearly better. That's the Classic-style class design philosophy Blizzard explicitly says Forever is trying to preserve.
