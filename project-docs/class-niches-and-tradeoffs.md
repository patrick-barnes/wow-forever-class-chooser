# Class Niches and Tradeoffs

| Class | Forever's defining niche | Major tradeoff |
|---|---|---|
| **Druid** | **Versatility — can do every role** | Less specialized utility/control |
| **Hunter** | **Longest-range physical DPS + pets** | Dead zone; no stun/interrupt |
| **Mage** | **Best ranged AoE + exceptional control** | Extremely fragile |
| **Paladin** | **Support/utility + strongest single-target healing** | Poor ranged/control toolkit |
| **Priest** | **Most versatile healer + absorption shields** | Fragile and vulnerable |
| **Rogue** | **Best sustained single-target melee DPS + stealth/control** | Little group support; melee only |
| **Shaman** | **Totems and extraordinary group utility** | Weak crowd control |
| **Warlock** | **DoTs/demons/drains and sustained caster pressure** | Physically vulnerable |
| **Warrior** | **Melee mastery + sustained multi-target melee damage** | Poor self-recovery |
